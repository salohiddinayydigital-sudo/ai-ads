# Viral kontentni teskari muhandislik qilish

Nima ishlashini taxmin qilish o'rniga, nishangizdagi eng yaxshi natijali kontentni tizimli tahlil qiling va isbotlangan naqshlarni ajratib oling.

## Mundarija
- 6 qadamli freymvork (Niche ID, Scrape, Analyze, Playbook, Layer Voice, Convert)
- Formula
- Teskari muhandislik cheklisti

## 6 qadamli freymvork

### 1. NICHE ID — Top yaratuvchilarni toping

Sohangizda doimiy yuqori engagement oladigan 10–20 yaratuvchini aniqlang:

**Tanlash mezonlari:**
- Izchil post qiladi (haftasiga 3+ marta)
- Follower soniga nisbatan yuqori engagement rate
- Maqsadli bozoringiz bilan auditoriya kesishmasi
- Mustahkam va ko'tarilayotgan yaratuvchilar aralashmasi

**Ularni qayerdan topish:**
- LinkedIn: soha kalit so'zlari bo'yicha qidiring, "People also viewed" ni tekshiring
- Twitter/X: nishon auditoriyangiz kimni kuzatishi va kim bilan jalb qilishini tekshiring
- SparkToro, Followerwonk kabi asboblardan yoki qo'lda tadqiqotdan foydalaning
- Soha newsletter'larida kim ko'rsatilishiga qarang

### 2. SCRAPE — Postlarni katta ko'lamda yig'ing

Tahlil uchun aniqlangan yaratuvchilardan 500–1000+ post yig'ing:

**Asboblar:**
- **Apify** — LinkedIn scraper, Twitter scraper aktorlari
- **Phantom Buster** — Ko'p platformali avtomatlashtirish
- **Eksport asboblari** — Platformaga xos eksport funksiyalari
- **Qo'lda yig'ish** — Kichik ma'lumotlar to'plami uchun jadvalga nusxalash/joylashtirish

**Yig'iladigan ma'lumotlar:**
- Post matni/kontenti
- Engagement metrikalari (yoqishlar, izohlar, ulashishlar, saqlashlar)
- Post formati (faqat matn, karusel, video, rasm)
- Post vaqti/kuni
- Hook/birinchi qator
- Ishlatilgan CTA
- Mavzu/tema

### 3. ANALYZE — Aslida nima ishlashini ajratib oling

Naqshlarni topish uchun ma'lumotlarni saralang va tahlil qiling:

**Miqdoriy tahlil:**
- Postlarni engagement rate bo'yicha tartiblang
- Top 10% natijadorlarni aniqlang
- Format naqshlarini qidiring (karusellar yaxshiroqmi?)
- Vaqt naqshlarini tekshiring (eng yaxshi kunlar/vaqtlar)
- Mavzu natijadorligini solishtiring

**Sifatiy tahlil:**
- Top postlar qanday hooklardan foydalanadi?
- Yuqori natijali postlar qanchalik uzun?
- Qanday hissiy triggerlar paydo bo'ladi?
- Qaysi formatlar takrorlanadi?
- Qaysi mavzular izchil yaxshi ishlaydi?

**Javob berish kerak bo'lgan savollar:**
- Top postlarning o'rtacha uzunligi qancha?
- Top 10% da qaysi hook turlari ko'proq uchraydi?
- Qaysi CTA'lar ko'proq izoh keltiradi?
- Qaysi mavzular ko'proq saqlanadi/ulashiladi?

### 4. PLAYBOOK — Naqshlarni kodlang

Foydalansa bo'ladigan takrorlanuvchi naqshlarni hujjatlashtiring:

**Kodlanadigan hook naqshlari:**
```
Naqsh: "Men [kutilmagan harakat] qildim va [hayratlanarli natija]"
Misol: "Men har kuni post qilishni to'xtatdim va engagement'im ikki baravar oshdi"
Nega ishlaydi: Qiziqish bo'shlig'i + qarama-qarshilik

Naqsh: "[Aniq son] ta [narsa], ular [natija]:"
Misol: "Menga $50K ga tushgan 7 ta narxlash xatosi:"
Nega ishlaydi: Aniqlik + yo'qotishdan qochish

Naqsh: "[Munozarali fikr]"
Misol: "Cold outreach o'ldi."
Nega ishlaydi: Pattern interrupt + bahsga taklif
```

**Format naqshlari:**
- Karusel: Hook slayd → Muammo → Yechim qadamlari → CTA
- Thread: Hook → Va'da → Yetkazish → Xulosa → CTA
- Hikoya posti: Hook → Setup → To'qnashuv → Yechim → Saboq

**CTA naqshlari:**
- Savol: "Nimani qo'shgan bo'lardingiz?"
- Kelishuv: "Roziman yoki yo'q?"
- Ulashish: "Bunga muhtoj odamni belgilang"
- Saqlash: "Keyinroq uchun saqlang"

### 5. LAYER VOICE — Direct response tamoyillarini qo'llang

Isbotlangan naqshlarni olib, ularni quyidagi ovoz tamoyillari bilan o'zingiznikiga aylantiring:

**"Nimanidir tushunib yetgan aqlli do'st"**
- Do'stingizga maslahat yozayotgandek yozing
- Ma'ruzalar emas, kashfiyotlarni ulashing
- "Siz ... qilishingiz kerak" emas, "Men ... ni topdim" ishlating
- Foydali bo'ling, va'zxon emas

**Aniq > Noaniq**
```
❌ "Men yaxshi daromad qildim"
✅ "Men $47 329 topdim"

❌ "Biroz vaqt oldi"
✅ "47 kun ketdi"

❌ "Ko'p odamlar"
✅ "2 847 kishi"
```

**Qisqa. Nafas oling. Yetkazing.**
- Har bir gapda bitta g'oya
- Qator uzilishlaridan keng foydalaning
- Muhim fikrlar yolg'iz tursin
- Ritm yarating: qisqa, qisqa, uzunroq tushuntirish

```
❌ "Men biznesimni uch yil noto'g'ri qurdim, nihoyat muvaffaqiyat kaliti kamroq narsalarga e'tibor qaratish va ularni a'lo darajada bajarish ekanini anglab yetdim."

✅ "Men 3 yil noto'g'ri qurdim.

Keyin tushundim.

Kamroqqa e'tibor qarating.
Uni a'lo darajada qiling.

Hammasi o'zgardi."
```

**Hissiyotdan yozing**
- Nima qilganingizdan emas, qanday his qilganingizdan boshlang
- Hissiy so'zlardan foydalaning: asabiylashgan, hayajonlangan, qo'rqib ketgan, berilib ketgan
- Samimiy bo'lganda zaiflikni ko'rsating
- Hissni saboqqa bog'lang

```
❌ "Narxlash haqida nimani o'rgandim"

✅ "Narxlarimni ko'tarishdan qo'rqardim.

Emailni yuborganimda qo'llarim titrardi.

Mana nima bo'ldi..."
```

### 6. CONVERT — E'tiborni harakatga aylantiring

Jalb qilishdan biznes natijalariga ko'prik quring:

**Yumshoq konversiyalar:**
- Bio/izohlarda newsletter'ga obuna
- Keyingi izohlarda bepul resurs takliflari
- DM triggerlari ("X deb izohlang, men sizga yuboraman...")
- Profil tashriflari → aniq CTA bilan optimallashtirilgan profil

**To'g'ridan-to'g'ri konversiyalar:**
- Izohlardagi havola (LinkedIn'da post matnida emas)
- Qimmatli kontent ichida kontekstli mahsulot eslatmalari
- Ishingizni tabiiy ko'rsatadigan keys postlar
- "Bu bo'yicha yordam kerak bo'lsa, DM yozing" (tejamkorlik bilan)

---

## Formula

```
1. Allaqachon nima ishlayotganini toping (taxmin qilmang)
2. Naqshlarni ajratib oling (hooklar, formatlar, CTA'lar)
3. Ustiga o'z samimiy ovozingizni qo'shing
4. O'z ma'lumotlaringiz asosida sinang va takrorlang
```

## Teskari muhandislik cheklisti

- [ ] Nishadagi 10–20 ta top yaratuvchini aniqladim
- [ ] Tahlil uchun 500+ post yig'dim
- [ ] Engagement rate bo'yicha tartibladim
- [ ] Top 10 hook naqshini hujjatlashtirdim
- [ ] Top 5 format naqshini hujjatlashtirdim
- [ ] Top 5 CTA naqshini hujjatlashtirdim
- [ ] Ovoz yo'riqnomalarini yaratdim (aniqlik, qisqalik, hissiyot)
- [ ] Naqshlardan shablonlar kutubxonasini qurdim
- [ ] O'z kontent natijalarimni kuzatishni sozladim
