# 📈 CONTEXT MODE: SCALE & OPTIMIZATION

- **Vertikal Scaling Qonuni:** Learning phase buzilmasligi uchun kunlik byudjet har 48–72 soatda ko'pi bilan **+20%** ga oshiriladi (`tools/spend-guard.py budget`).
- **Gorizontal Scaling Qonuni:** G'olib kreativ (`Winner`) topilganda byudjetni 5x sakratish o'rniga yangi creative angle variatsiyalari (`More -> Better -> New`, [[more-better-new]]) va yangi auditoriya qatlamlari (Broad / LAL 1% / Solventnost stack) ochiladi.
- **Kill / Keep / Scale Mezonlari:**
  - **KILL:** Sarf `>= 2x Target CPA` va `0` konversiya, yoki 7 kunlik `ROAS < Break-even ROAS`.
  - **KEEP:** `CPA <= Target CPA`, `Frequency < 2.5` (TOF), `FTIR >= 60%`.
  - **SCALE:** `CPA <= 0.8x Target CPA` kamida 3–5 kun barqaror va `Overlap < 20%`.
