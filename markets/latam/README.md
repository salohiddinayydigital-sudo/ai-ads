# Bozor paketi: Lotin Amerikasi (Braziliya, Meksika, Kolumbiya, Chili) (`latam`)

- **Standart valyuta:** `BRL` (qo'llab-quvvatlanadi: `BRL, MXN, COP, CLP, ARS, USD`)
- **To'lov usullari:** Pix (Brazil — Instant), Cartao de Credito Parcelado (Installments), OXXO / SPEI (Mexico), Mercado Pago
- **BNPL provayderlar:** Mercado Credito, Parcelado sem juros (Up to 12x), Kueski Pay (MX), Addi (CO)
- **Narx anker shabloni:** `Em ate 12x de {installment} sem juros ou 5% OFF no Pix`
- **Asosiy voronkalar:**
  - Reklama -> Click-to-WhatsApp (CTWA) -> Automated WhatsApp Flow / Sales Rep -> Pix / Payment Link
  - Reklama -> E-Commerce / Mercado Libre -> Pix / Installment Checkout
- **Xabar kanallari:** WhatsApp Business (95%+ reach), Instagram DM
- **Maxfiylik va reklama qonunchiligi:**
  - Braziliya LGPD (Lei Geral de Protecao de Dados, 13.709/2018-sonli qonun)
  - CONAR (Braziliya reklama o'z-o'zini tartibga solish tashkiloti)
  - Meksika LFPDPPP
- **Tillar (BCP 47):** `pt-BR, es-MX, es-419, en` (RTL: `yo'q`)
- **Tekshirilgan sana:** `2026-10-21`
