# Bozor paketi: O'zbekiston va Markaziy Osiyo (`uz`)

- **Standart valyuta:** `UZS` (qo'llab-quvvatlanadi: `UZS, USD`)
- **To'lov usullari:** Payme, Click, Uzcard, Humo, Visa/Mastercard
- **BNPL provayderlar:** Uzum Nasiya, Alif Nasiya, Anorbank Nasiya, Intend
- **Narx anker shabloni:** `Oyiga atigi {installment} dan ({bnpl} orqali 12 oyga bo'lib to'lash)`
- **Asosiy voronkalar:**
  - Reklama -> Telegram Bot / Mini App -> AmoCRM / Bitrix24 -> Call Center (15-min SLA)
  - Reklama -> Instagram Direct / Lead Form -> AmoCRM -> Sales Call
  - Reklama -> Marketplace (Uzum Market) / Web Checkout (Payme/Click)
- **Xabar kanallari:** Telegram (90%+ penetration), Instagram DM, SMS, WhatsApp
- **Maxfiylik va reklama qonunchiligi:**
  - O'zbekiston Respublikasining 'Shaxsga doir ma'lumotlar to'g'risida'gi Qonuni (O'RQ-547)
  - O'zbekiston Respublikasining 'Reklama to'g'risida'gi Qonuni (O'RQ-776)
- **Tillar (BCP 47):** `uz-Latn, uz-Cyrl, ru, en` (RTL: `yo'q`)
- **Tekshirilgan sana:** `2026-10-21`
