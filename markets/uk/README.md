# Bozor paketi: Buyuk Britaniya (UK) (`uk`)

- **Standart valyuta:** `GBP` (qo'llab-quvvatlanadi: `GBP`)
- **To'lov usullari:** Visa/Mastercard, Apple Pay, PayPal, Open Banking
- **BNPL provayderlar:** Klarna, Clearpay, PayPal Pay in 3
- **Narx anker shabloni:** `Or 3 interest-free payments of {installment} with {bnpl}`
- **Asosiy voronkalar:**
  - Reklama -> PECR/UK-GDPR Consent Banner -> Shopify/WooCommerce -> Apple Pay / Klarna Checkout
  - Reklama -> Lead Form / Landing Page -> CRM -> Inside Sales
- **Xabar kanallari:** WhatsApp, Email, SMS, Instagram DM
- **Maxfiylik va reklama qonunchiligi:**
  - UK GDPR va Data Protection Act 2018
  - PECR (Maxfiylik va elektron aloqa qoidalari)
  - Google Consent Mode v2 (UK)
  - ASA CAP Code & FCA Financial Promotions Regime
- **Tillar (BCP 47):** `en-GB` (RTL: `yo'q`)
- **Tekshirilgan sana:** `2026-10-21`
