# Paid Media Reference Benchmarks — United Kingdom (UK) (`uk`)

> **Rule #1 (Account History First / Akkaunt tarixi birinchi):** Always prioritize the ad account's own 30-to-90-day historical baseline over external industry ranges. Use the ranges below **only** as cold-start reference intervals for new accounts with zero historical data.

- **Market:** `uk` (United Kingdom (UK))
- **Currency Basis:** GBP
- **Confidence Level:** Medium (Cold-Start Reference Only; +/- 35% variance by creative quality and AOV)
- **Verified Date:** `2026-10-21`

| Metric | Cold-Start Reference Range (Meta / Paid Social) | Notes |
|---|---|---|
| **CPM** | `£9.00 - £21.00` | Q4 / Peak season adds +30% to +80% auction pressure |
| **Outbound CTR** | `0.90% - 1.85%` | Below lower bound indicates hook / thumbstop bottleneck |
| **Link CPC** | `£0.65 - £2.30` | Derived from CPM and Outbound CTR |
| **Landing Page / Lead CVR** | `1.8% - 3.8%` | E-Commerce checkout vs Lead Gen / Messaging funnel |
| **Target ROAS (Cold)** | `2.1x - 4.0x` | Must always be validated against `calculator.py breakeven` |
