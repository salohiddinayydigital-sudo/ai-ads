# Bozor paketi: Janubi-Sharqiy Osiyo (SG, ID, TH, VN, MY, PH) (`sea`)

- **Standart valyuta:** `SGD` (qo'llab-quvvatlanadi: `SGD, IDR, THB, VND, MYR, PHP, USD`)
- **To'lov usullari:** GrabPay, GoPay / OVO / QRIS (ID), PromptPay / TrueMoney (TH), GCash (PH), PayNow (SG), COD
- **BNPL provayderlar:** Atome, Shopee SPayLater, Grab PayLater, Kredivo
- **Narx anker shabloni:** `3x 0% installments of {installment} with {bnpl}`
- **Asosiy voronkalar:**
  - Collaborative Ads (CPAS) / TikTok Shop -> Shopee / Lazada / TikTok Shop ilova ichidagi checkout
  - Reklama -> LINE Official Account (TH) / WhatsApp (SG/MY/ID) / Messenger (PH/VN) -> Order
- **Xabar kanallari:** WhatsApp (SG/MY/ID), LINE Official Account (TH), Zalo / Messenger (VN), Messenger (PH)
- **Maxfiylik va reklama qonunchiligi:**
  - Singapur PDPA
  - Tailand PDPA
  - Indoneziya PDP qonuni (UU No. 27 Tahun 2022)
- **Tillar (BCP 47):** `en-SG, id, th, vi, ms, tl` (RTL: `yo'q`)
- **Tekshirilgan sana:** `2026-10-21`
