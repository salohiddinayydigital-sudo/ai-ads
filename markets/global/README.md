- **Standart valyuta:** `USD` (qo'llab-quvvatlanadi: `USD, EUR, GBP, CAD, AUD, JPY, SGD, AED, BRL, INR, UZS`)
- **To'lov usullari:** Credit/Debit Cards (Visa, Mastercard, Amex), Apple Pay, Google Pay, PayPal, Stripe, Shop Pay
- **BNPL provayderlar:** Klarna, Afterpay / Clearpay, Affirm, PayPal Pay in 4
- **Narx anker shabloni:** `Or 4 interest-free payments of {installment} with {bnpl}`
- **Asosiy voronkalar:**
  - To'g'ridan-to'g'ri iste'molchiga (Reklama -> Product Landing Page -> Cart -> Checkout)
  - B2B SaaS / High-Ticket (Reklama -> Lead Magnet / VSL -> Qualification Form -> CRM / Calendly)

  - Meta Limited Data Use (LDU)
