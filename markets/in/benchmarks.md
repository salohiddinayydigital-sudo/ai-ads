# Paid Media Reference Benchmarks — India (IN) (`in`)

> **Rule #1 (Account History First / Akkaunt tarixi birinchi):** Always prioritize the ad account's own 30-to-90-day historical baseline over external industry ranges. Use the ranges below **only** as cold-start reference intervals for new accounts with zero historical data.

- **Market:** `in` (India (IN))
- **Currency Basis:** INR / USD
- **Confidence Level:** Medium (Cold-Start Reference Only; +/- 35% variance by creative quality and AOV)
- **Verified Date:** `2026-10-21`

| Metric | Cold-Start Reference Range (Meta / Paid Social) | Notes |
|---|---|---|
| **CPM** | `₹120 - ₹450 ($1.40 - $5.40)` | Q4 / Peak season adds +30% to +80% auction pressure |
| **Outbound CTR** | `1.00% - 2.10%` | Below lower bound indicates hook / thumbstop bottleneck |
| **Link CPC** | `₹8 - ₹42 ($0.10 - $0.50)` | Derived from CPM and Outbound CTR |
| **Landing Page / Lead CVR** | `1.5% - 4.0%` | E-Commerce checkout vs Lead Gen / Messaging funnel |
| **Target ROAS (Cold)** | `2.5x - 5.0x` | Must always be validated against `calculator.py breakeven` |
