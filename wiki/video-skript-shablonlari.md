# Video skript shablonlari (9 format)

> Bog'lanishlar: [[video-kreativ-tizimi]] · [[kopirayter-frameworklar]] · [[sop-meta-reklama-matni]] · [[kreativ-sikl]]

Har shablon: **hook (0-3s) → tana → proof → CTA**. `{}` — to'ldiriladi.
Hook qoidasi: 8-12 so'z, mustaqil ma'no, ovozsiz ham tushunarli (subtitr).

## 1. 50/50 (reaksiya)
```
Hook:   "{savol yoki da'vo} haqida gapirishyapti — men buni {narsa} bilan sinab ko'rdim."
Tana:   {kutilgan vs haqiqat} — "{aniq natija/raqam}"
Proof:  {ko'rsatiladigan natija / skrinshot}
CTA:    "{nima qilish} — {nima oladi}"
```

## 2. Savol-Javob
```
Hook:   "{mijozning eng ko'p beradigan savoli}?"
Tana:   Qisqa javob (2-3 jumla) → sabab
Proof:  {misol / raqam}
CTA:    "Savolingiz bormi — {kanal}da yozing."
```

## 3. Ekspert
```
Hook:   "{nisha}da {xato} — sababi {kutilmagan sabab}."
Tana:   3 qadam: {1}, {2}, {3}
Proof:  "{N} loyihada shu ishladi" / sertifikat / keys
CTA:    "{harakat} — {nima oladi}"
```

## 4. Face-to-camera
```
Hook:   "Agar {vaziyat} bo'lsa — bu videoni oxirigacha ko'ring."
Tana:   {muammo} → {nega muhim} → {yechim}
Proof:  {dalil}
CTA:    "{kanal}da yozing — {aniq natija}"
```

## 5. Storytell
```
Hook:   "{vaqt} oldin {qahramon} {muammo} bilan keldi."
Tana:   {to'siq} → {burilish} → {yechim}
Proof:  {aniq natija, raqam}
CTA:    "Siz ham xohlasangiz — {harakat}"
```

## 6. Syujetli
```
Hook:   {qiziqarli sahna/voqea} — lekin {kutilmagan bog'lanish}
Tana:   {sahna} → {mahsulot/xizmat} bilan bog'lanish
Proof:  {natija}
CTA:    "{harakat}"
```

## 7. Ekstremal
```
Hook:   "{mahsulot}ni {qiziq shart}da sinab ko'rdim."
Tana:   {jarayon} → {natija}
Proof:  {ko'rinadigan natija}
CTA:    "{harakat}"
```

## 8. Shaxsiyatni ochish
```
Hook:   "{shaxsiy fikr/tajriba} haqida hech kim aytmaydi."
Tana:   {fikr} → {sabab} → {nima o'zgardi}
Proof:  {shaxsiy natija / mijoz natijasi}
CTA:    "{harakat}"
```

## 9. Solishtirish
```
Hook:   "{A} yoki {B}? Men ikkalasini sinab ko'rdim."
Tana:   A: {natija} · B: {natija}
Proof:  {raqam bilan taqqoslash}
CTA:    "Xohlasangiz — {harakat}"
```

## Umumiy tekshiruv (har skriptdan keyin)

- [ ] Hook 0-3s, ovozsiz tushunarli
- [ ] Bitta asosiy va'da (ikkita emas)
- [ ] Proof/mexanizm bor — faqat va'da emas
- [ ] CTA destination bilan mos (Telegram/landing)
- [ ] Isbotsiz da'vo, "eng yaxshi", raqamsiz gaplar yo'q
- [ ] Spec chegaralari joriy rasmiy manbadan ([[video-kreativ-tizimi]])
