# E'tirozlar va matnli javob patternlari

> Bog'lanishlar: [[cialdini-7-printsip]] · [[zaifdan-kuchli-matn]] · [[lead-magnet-yetkazish-nomlash]] · [[sotuv-va-retention]]

**Asosiy qoida:** e'tiroz FAQ bo'limida emas, **paydo bo'lgan joyida** hal qilinadi —
narx e'tirozi narx yonida, "menga to'g'ri kelmaydi" hero yonida.

## 1. "Qimmat" — haqiqiy ma'nosi: "qiymatini ko'rmayapman"

| Pattern | Shablon |
|---|---|
| Xarajatga bo'lish | `{narx} — bu kuniga {kichik summa}. Bir piyola choydan arzon.` |
| Yo'qotish bilan solishtirish | `Har oy {muammo} sizga {summa} turadi. Bu {marta} baravar ko'p.` |
| Muqobil bilan solishtirish | `{muqobil} {narx2} turadi va {kamchilik}.` |
| Qiymat yig'indisi | `Alohida: {a} + {b} + {c} = {jami}. Birga — {narx}.` |
| Risk qaytarish | `{muddat} ichida {natija} bo'lmasa — pulingiz qaytadi.` |

Ishlamaydi: "narximiz hamyonbop", "arzon narxlar", "moslashuvchan narx siyosati".

## 2. "Vaqtim yo'q"

| Pattern | Shablon |
|---|---|
| Vaqt hisobi | `Sizdan {aniq vaqt} kerak. Qolganini biz qilamiz.` |
| Vaqt qaytishi | `{muddat} sarflaysiz — har oy {ko'p vaqt} qaytadi.` |
| Jarayon soddaligi | `3 qadam: {1}, {2}, {3}. Boshqa hech narsa.` |

## 3. "Ishonmayman" — O'zbekistonda eng kuchli e'tiroz

| Pattern | Shablon |
|---|---|
| Tekshiriladigan dalil | `Mana {mijoz} sayti: {link}. Qo'ng'iroq qilib so'rang.` |
| Bosqichma-bosqich to'lov | `50% oldindan, 50% natijadan keyin.` |
| Avval natija | `Birinchi {narsa}ni bepul qilaman. Yoqmasa — to'lamaysiz.` |
| Jonli aloqa | `Telefon: {raqam}. Manzil: {aniq manzil}.` |
| Videoli sharh | Matnli sharhdan ancha kuchli — asosiy ishonch signali |

## 4. "Menga to'g'ri kelmaydi"

| Pattern | Shablon |
|---|---|
| Aniq kvalifikatsiya | `Bu {aniq kim} uchun. Agar siz {holat} bo'lsangiz — to'g'ri kelmaydi.` |
| Segment ro'yxati | `Kim uchun: {a}, {b}. Kim uchun emas: {d}, {e}.` |
| O'xshash keys | `{O'xshash biznes} ham shunday o'ylagan edi. Natija: {raqam}.` |

## 5. "Keyinroq"

| Pattern | Shablon |
|---|---|
| Kechikish narxi | `Har kechikkan oy — {yo'qotish}.` |
| Haqiqiy cheklov | `{sana}gacha {aniq sabab}. Keyin {nima o'zgaradi}.` |

> Soxta shoshilinchlik ("faqat bugun!" har kuni) brendni yo'q qiladi. Cheklov haqiqiy bo'lsin.

## 6. "Nima uchun aynan siz?"

Faqat bitta javob ishlaydi: **raqib ayta olmaydigan narsa.**
"Sifat", "tajriba", "mas'uliyat" — hammasi ayta oladi, demak hech narsa emas.

```
Shablon: {faqat sizda bor narsa} — {buni tekshirish yo'li}
```
